## Vercel Deployment

Vercel은 서버리스 환경이므로 `market.db` 같은 SQLite 파일을 영구 쓰기 DB로 사용하는 방식이 적합하지 않습니다. 주문 등록, 재고 감소, 자동 발주 생성, 발주 상태 변경처럼 DB 변경이 필요한 기능은 외부 DB에 저장되어야 합니다.

이 프로젝트는 실행 환경을 다음처럼 분리합니다.

```text
Local:
  web_app.py + market.db

Vercel:
  api/index.py + Turso/libSQL remote database
```

Vercel 배포용 주요 파일:

```text
api/index.py
database.py
sample_query_runner.py
seed_remote.py
requirements.txt
vercel.json
.env.example
```

## Vercel Deployment Steps

### 1. Create External DB

Turso에서 새 데이터베이스를 만든 뒤 DB URL과 인증 토큰을 준비합니다.

필요한 환경변수:

```text
SECRET_KEY
TURSO_DATABASE_URL
TURSO_AUTH_TOKEN
```

`.env.example`을 참고해서 로컬 테스트용 `.env`를 만들 수 있습니다. 실제 `.env` 파일은 git에 올리지 않습니다.

### 2. Seed Remote DB

환경변수를 설정한 뒤 원격 DB를 초기화합니다.

```bash
python seed_remote.py --reset
```

초기화 후 데이터 개수 기준:

```text
retailer: 1
store: 10
brand: 15
product_category: 15
supplier: 5
supplier_brand: 22
product: 80
customer: 25
orders: 1500
purchase_order: 150
```

### 3. Push To GitHub

```bash
git add .
git commit -m "Add Vercel deployment support"
git push
```

### 4. Import Project In Vercel

1. Vercel에서 GitHub 저장소를 import합니다.
2. Framework Preset은 `Other` 또는 Python 기준으로 설정합니다.
3. Environment Variables에 아래 값을 등록합니다.

```text
SECRET_KEY
TURSO_DATABASE_URL
TURSO_AUTH_TOKEN
```

4. Deploy를 실행합니다.

배포 후 접속 주소는 다음 형태입니다.

```text
https://프로젝트명.vercel.app
```

## Troubleshooting

- Vercel 환경변수에 `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `SECRET_KEY`가 등록되어 있는지 확인합니다.
- 원격 DB에 `seed_remote.py --reset`으로 초기 데이터가 들어갔는지 확인합니다.
- Vercel Function Logs에서 DB 연결 오류 또는 SQL 오류를 확인합니다.
- 로컬 `market.db`와 Vercel 원격 DB는 서로 다른 DB이므로, 로컬에서 변경한 데이터가 자동으로 Vercel에 반영되지는 않습니다.
