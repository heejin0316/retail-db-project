# Sample Query Description

이 문서는 `queries/sample_queries.sql`에 작성된 sample query 5개의 목적과 조회 기준을 설명한다.

## Query 1. 각 매장별 가장 많이 판매된 상위 20개 제품 조회

### 목적

각 매장에서 어떤 제품이 많이 판매되었는지 확인하기 위한 쿼리이다. 매장별 인기 상품을 파악하여 재고 관리나 상품 배치에 활용할 수 있다.

### 사용 테이블

- `orders`
- `store`
- `product`

### 조회 기준

- 판매량 기준은 `SUM(o.quantity)`이다.
- 매장별로 제품 판매 수량을 합산한다.
- `ROW_NUMBER()`를 사용해 각 매장 안에서 판매량 순위를 매긴다.
- 각 매장별 상위 20개 제품만 조회한다.
- 정렬 기준은 매장명, 판매량 내림차순이다.

## Query 2. 캠퍼스 구역별 가장 많이 판매된 상위 20개 제품 조회

### 목적

매장을 캠퍼스 구역별로 묶어서 각 구역에서 가장 많이 판매된 제품을 확인하기 위한 쿼리이다. 현재 데이터에는 매장 주소가 없으므로 매장명을 기준으로 캠퍼스 구역을 분류한다.

### 사용 테이블

- `orders`
- `store`
- `product`

### 캠퍼스 구역 분류 기준

- `이대기숙사점` -> 기숙사 구역
- `이대과학관점` -> 과학관 구역
- `이대아산공학관점`, `이대아산공학관부속점` -> 아산공학관 구역
- `이대도서관점` -> 도서관 구역
- `이대경영관점` -> 경영관 구역
- `이대음악관점` -> 음악관 구역
- `이대조형관점`, `이대조형관위성점` -> 조형관 구역
- `이대학관점` -> 학관 구역

### 조회 기준

- 판매량 기준은 `SUM(o.quantity)`이다.
- 매장명에 포함된 단어를 기준으로 캠퍼스 구역을 분류한다.
- `ROW_NUMBER()`를 사용해 각 구역 안에서 판매량 순위를 매긴다.
- 각 구역별 상위 20개 제품만 조회한다.
- 정렬 기준은 캠퍼스 구역명, 판매량 내림차순이다.

## Query 3. 판매 실적이 우수한 상위 5개 매장 조회

### 목적

전체 매장 중 매출액이 높은 상위 매장을 확인하기 위한 쿼리이다. 매장별 판매 성과를 비교하는 데 사용한다.

### 사용 테이블

- `orders`
- `store`

### 조회 기준

- 판매 실적 기준은 `SUM(o.quantity * o.unit_price)`이다.
- 주문 수량과 판매단가를 곱해 주문별 매출액을 계산한다.
- 매장별 총매출액을 합산한다.
- 총매출액이 높은 순서로 상위 5개 매장을 조회한다.
- `LIMIT 5`를 사용한다.

## Query 4. 코카콜라 제품보다 노브랜드 콜라가 더 많이 판매된 매장의 수 조회

### 목적

특정 제품군 간 판매량을 비교하기 위한 쿼리이다. 코카콜라 제품보다 노브랜드 콜라가 더 많이 팔린 매장이 몇 개인지 확인한다.

### 사용 테이블

- `orders`
- `store`
- `product`

### 비교 제품 기준

코카콜라 제품 기준:

- `코카콜라 오리지널`
- `코카콜라 제로`

비교 제품:

- `노브랜드 콜라`

### 조회 기준

- 판매량 기준은 `SUM(o.quantity)`이다.
- 매장별로 코카콜라 제품 판매량과 노브랜드 콜라 판매량을 각각 합산한다.
- `노브랜드 콜라 판매량 > 코카콜라 제품 판매량`인 매장의 수를 계산한다.
- 기존 요구사항의 펩시콜라는 현재 제품 데이터에 없으므로, 실제 데이터에 존재하는 `노브랜드 콜라`로 비교 대상을 변경하였다.

## Query 5. 우유 제품 판매량이 있는 매장 중 판매량 상위 5개 조회

### 목적

우유 제품군이 어느 매장에서 많이 판매되는지 확인하기 위한 쿼리이다. 특정 제품군의 매장별 판매 성과를 분석하는 데 사용한다.

### 사용 테이블

- `orders`
- `store`
- `product`

### 우유 제품 기준

- `매일유업 매일우유 오리지널`
- `매일유업 소화가잘되는우유`
- `매일유업 상하목장 유기농우유`
- `노브랜드 굿밀크`

### 조회 기준

- 판매량 기준은 `SUM(o.quantity)`이다.
- 보조 판매 실적 기준은 `SUM(o.quantity * o.unit_price)`이다.
- 매장별 우유 제품 판매량과 판매금액을 합산한다.
- 우유 판매량이 높은 순서로 정렬한다.
- 판매량이 같으면 우유 제품 판매금액이 높은 순서로 정렬한다.
- `LIMIT 5`를 사용한다.

### 쿼리 변경 사유

초기 요구사항은 "우유와 함께 가장 많이 구매한 제품 상위 3개"였으나, 현재 `orders` 테이블은 하나의 주문 행이 하나의 제품만 나타내는 구조이다. 따라서 장바구니 단위의 동시 구매 분석보다는 현재 스키마와 데이터에 맞는 "우유 제품 판매량이 있는 매장 중 판매량 상위 5개" 쿼리로 변경하였다.
