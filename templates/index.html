Retail DB 관리 시스템

프로젝트 소개

본 시스템은 데이터베이스 과제 프로젝트로 구현된 소매 유통 관리 웹 인터페이스입니다.
Python + SQLite 기반으로 구축되었으며, Flask를 통해 웹 기능을 제공합니다.
기존 CLI(app.py)와 동일한 비즈니스 규칙을 공유합니다.

🛒 고객 주문 등록

고객ID, 제품ID, 수량을 입력하여 주문을 등록합니다.
재고 확인 후 자동으로 재고를 차감합니다.

📦 매장 재고 조회

매장별 제품 재고 목록을 조회합니다.
재주문 필요 여부를 한눈에 확인할 수 있습니다.

🔄 자동 재주문 발주 생성

재고가 재주문 기준 이하인 제품을 자동으로 감지하여
발주를 일괄 생성합니다.

📋 공급업체 발주 처리

발주 상태를 단계별로 변경합니다.
REQUESTED → APPROVED → SHIPPED → COMPLETED

📊 Sample Query 실행

사전 정의된 5개의 분석 쿼리를 실행하고
결과를 화면에서 확인합니다.
